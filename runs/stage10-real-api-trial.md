## 结论与发现

- 暂停/续做、失败记录、引句校验与输入来源记录在真实 API 下均按预期工作。
- 全文读取：有 `doc_id` 的项目可成功读取全文；无检索快照的项目只能使用摘要，并记录“没有可用全文，使用摘要”。
- 发现的问题：本地旧数据库在 v14 时缺少 `evidence_item_versions.error` 列（历史本地构建遗留），导致读取证据状态报错；已通过 Schema v15 迁移补列修复，并补充版本断言。
- 真实审核项目缺少检索快照/`doc_id`，因此该项目本身无法覆盖全文场景；全文场景由“剪力墙自动布置”项目补齐。
- 试运行使用的 Key 仅存在于本地临时文件，未写入数据库、日志或仓库；运行报告中的逐篇标题与摘要内容未入库，本记录只保留聚合结果。

## 复现要点

- 选择包含检索快照的项目可获得 `doc_id` 并读取全文；仅有手工导入候选的项目只能使用摘要。
- 首轮设置较小的“单次运行最多 AI 请求”即可观察暂停与续做；对无文本条目重试不会成功，应新建任务。

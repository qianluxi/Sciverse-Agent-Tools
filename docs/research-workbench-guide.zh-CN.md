# 科研工作台新手指引（含完整示例）

本文用一个具体示例，带你从新建项目走到导出报告。示例中的论文题名、DOI 和决定均为演示数据，不是真实研究结论。

## 1. 先看一个 10 分钟最小示例

### 示例项目

- 项目名：`RC 柱抗震加固-示例`
- 研究问题：建筑钢筋混凝土柱的抗震加固方法对其承载力、延性和滞回性能有什么影响？
- 纳入标准（示例，实际请按研究方案填写）：
  - I1 研究对象是建筑 RC 柱或梁柱节点
  - I2 涉及抗震加固、修复或改造
  - I3 评估抗震性能、承载力、延性、滞回性能或破坏模式
  - I4 试验、数值或分析研究
  - I5 摘要可用，或题名足以判断
- 排除标准（示例）：
  - E1 桥梁柱/墩、板柱节点、剪力墙、砌体、整体建筑
  - E2 与抗震加固/修复无关
  - E3 只讨论成本、环境或生命周期
  - E4 综述、非原始研究，或信息不足

### 步骤 1：启动并填 Token

1. 双击 `dist\SciverseResearchWorkbench.exe`（或运行 `research_app/Start-Research-App.bat`）。
2. 左侧输入 Sciverse API Token（不是 AI Key），点击连接/检索。
3. AI 功能需要另外填 OpenAI 兼容服务的 Base URL、API Key 和模型名；没有 AI Key 不影响检索、筛选和报告。

### 步骤 2：新建项目

进入左侧“研究项目”：

1. 填写项目名 `RC 柱抗震加固-示例`。
2. 研究问题填上面的示例问题。
3. 纳入/排除标准按 I1–I5、E1–E4 填写。
4. 保存后，项目会出现在所有页面的“当前项目”选择器中。

### 步骤 3：检索并加入候选

回到主页检索：

- 示例检索词：`seismic retrofit reinforced concrete column`
- 建议年份：2015–2025
- 示例选择 6 篇（演示用，DOI 为虚构）：
  | 示例文献 | 说明 |
  |---|---|
  | FRP 包裹 RC 柱滞回性能试验 | 应纳入 |
  | 钢套管加固 RC 柱拟静力试验 | 应纳入 |
  | 外包钢加固梁柱节点试验 | 应纳入 |
  | 桥梁墩柱抗震加固 | 应排除（对象不符） |
  | RC 柱抗震加固综述 | 应排除（综述） |
  | 无摘要会议论文 | 信息不足，先待定 |

勾选这 6 篇，点击“加入项目”。

### 步骤 4：题名/摘要筛选

进入左侧“系统综述筛选”：

1. 队列默认按题名稳定排序，显示题名和摘要。
2. 对 6 篇分别决定：
   - 3 篇纳入（前三篇）
   - 2 篇排除：桥梁文献选“主题不相关”，综述选“研究类型不符”
   - 1 篇待定：无摘要会议论文
3. 每次保存都会写入审计；“原备注”是历史值，当前备注以队列为准。
4. 在“审计记录”确认 5 条人工决定有记录；在“导出与 PRISMA”查看数量。

此时示例计数应为：识别 6、去重 0、题摘待定 1、纳入 3、排除 2。注意：这里的“纳入”只是题名/摘要纳入，不是最终纳入。

### 步骤 5：可选 AI 筛选建议

进入“AI 筛选建议”：

1. 左侧填 AI Key 和模型（示例用 `glm-5.3-flash`）。
2. 选择 6 篇，点击“生成 AI 筛选建议”。
3. AI 会给出“建议纳入/建议排除/需人工判断”、命中标准、理由和原文引句。
4. 可以点“采纳此 AI 建议”，或修改后保存；也可以“全部按 AI 建议预填”，再逐条核对后点“保存全部当前决定”。
5. AI 不会自动改变筛选状态，尤其不会自动排除文献。

### 步骤 6：完整示例的后续（可选）

如果要把示例做完整，继续以下步骤：

1. **项目证据矩阵**：选 3 篇题摘纳入文献，新建任务并冻结输入；分批运行。审核时对比 AI 原始、人工校正、最终采用三个版本，保存人工校正或标记最终采用。
2. **研究报告**：为题摘纳入的 3 篇记录全文阶段：
   - 1 篇“全文纳入”
   - 1 篇“全文排除”，原因如“研究对象不符”
   - 1 篇“无法获取全文”
   报告会显示：题摘纳入 3、全文纳入 1、全文排除 1、无法获取 1，最终纳入报告数 1。
3. **导出**：下载报告 Markdown/JSON、PRISMA 逐条记录 CSV、证据矩阵 CSV，或“可追溯成果包 ZIP”。
4. **协作审核（可选方法学模块）**：只有需要两人独立盲筛时使用。创建首位协调者并设置 PIN，再创建审核员；审核员各自解锁提交，协调者解锁后处理一致/冲突。单人使用可以跳过本页。
5. **基准评估（可选）**：有固定金标准集时，用独立基准项目评估 AI 的召回率、错误排除率等。

## 2. 页面速查

| 页面 | 什么时候用 | 关键操作 |
|---|---|---|
| 研究项目 | 一开始 | 新建项目、填写研究问题和纳排标准 |
| 主页检索 | 找文献 | 语义/条件检索，勾选后加入项目 |
| 系统综述筛选 | 题名/摘要筛选 | 纳入/排除/待定，查看审计和 PRISMA |
| AI 筛选建议 | 需要 AI 辅助时 | 生成建议、采纳/改判/拒绝，人工终审 |
| AI 领域扫描 | 快速了解领域 | 20 篇内部分类、概括、空白/痛点 |
| AI 证据与提纲 | 单次少量证据 | 最多 5 篇提取证据、生成提纲 |
| 项目证据矩阵 | 项目级证据整理 | 分片提取、暂停续做、失败重试、三版本审核 |
| 研究报告 | 交付前 | 全文阶段、PRISMA、报告与成果包 |
| 协作审核 | 双人盲筛时 | 角色、PIN、盲筛、冲突/原因分歧确认 |
| 引用网络 | 看引用关系 | 中心论文、一层关系、导出 GraphML/CSV |
| 趋势分析 | 看年份/期刊/关键词 | 统计、扩展采样、导出 ZIP/PNG |
| 图表证据板 | 提取图表 | 最多 5 篇、每篇 4 张，导出清单/图片 |
| 筛选基准评估 | 评估 AI 质量 | 固定金标准、召回率、错误排除率、不确定率 |

## 4. 常见问题

- **需要几个 Key？** Sciverse Token 用于检索和读全文；AI Key 只用于翻译、筛选建议、证据提取等 AI 功能。两者都不是必填项（AI 功能可不用）。
- **Token/Key 会保存吗？** Token 读环境变量或 `~/.sciverse/credentials.json`；AI Key 只在当前浏览器会话，不写数据库。
- **为什么检索总数显示“上限”？** 接口 `total_count` 最多 10000，达到上限时不要当作精确总数。
- **为什么报告里最终纳入是 0？** 只记录题名/摘要纳入还不够，必须在“研究报告”里记录全文阶段；未记录时系统会明确警告。
- **AI 会自己排除文献吗？** 不会。AI 只给建议，最终状态必须人工保存。
- **需要双人复核吗？** 个人使用不需要；系统综述方法学要求双人独立筛选时才用“协作审核”。该模块是可选功能。
- **旧数据库升级后审核人无法解锁？** 使用本机管理员命令 `python -m research_app.maintenance collab-init-legacy-pins` 初始化 PIN。
- **忘记 PIN？** 使用本机管理员命令 `python -m research_app.maintenance collab-reset-pin --reviewer-id <ID> --reason "..."`，需要独立管理员恢复密钥。

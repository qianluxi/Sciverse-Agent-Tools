# 筛选基准集归档（阶段 9）

本目录归档「AI 辅助题名/摘要筛选」阶段 9 使用的固定人工标注基准集的**元数据**，用于实验复核。为避免在公开仓库中引入受版权保护的完整摘要和原文引句，本目录只提交 DOI/稳定候选 ID、金标准标签、人工标注理由和输入哈希；包含完整题录与摘要的确认版文件保留在本地（见校验和）。

## 文件

- `rc-building-column-joints-v1.manifest.csv`：60 条基准候选的标识与标签清单。字段：`candidate_key`、`paper_id`、`year`、`title`、`doi`、`gold`（included/excluded）、`notes`（人工标注理由，如 `[人工审核] I1-I4：…`）、`abstract_sha256`（摘要输入哈希）。
- `dataset_checksums.sha256`：本地确认版文件与清单的 SHA-256。若审核者获得本地确认版文件，可据此核对冻结数据集未被篡改。
- 本地保留（未入库）：`rc-building-column-joints-v1.confirmed.json`、`rc-building-column-joints-v1.confirmed.csv`（含完整摘要）。

## 数据集

- 名称：`rc-building-column-joints-v1`（confirmed）
- 主题：建筑钢筋混凝土柱及梁柱节点的抗震加固方法及其对承载力、延性、滞回性能和破坏模式的影响
- 规模：60 条（金标准纳入 30、排除 30），全部经人工标注并复核，无「草案」残留
- 状态：`confirmed`，金标准在模型运行前冻结

## 纳入/排除标准（编号口径）

- 纳入（I1–I4）：建筑 RC 柱或梁柱节点；涉及抗震加固/修复/改造；评估抗震性能、承载力、延性、滞回性能或破坏模式；试验/数值/分析研究，且摘要可用或题名足以判断
- 排除（E1–E4）：非建筑 RC 柱/梁柱节点（桥梁柱/墩、板柱节点、剪力墙、整体框架/建筑、砌体等）；未涉及抗震加固/修复/改造；仅评估成本/环境/生命周期或非抗震荷载；综述、摘要不可用且题名不足以判断、或非原始研究

## 样本口径与分母（重要）

- 本基准为**单一测试批次**，未单独划分开发集/测试集；60 条均为该研究问题的固定标注集。
- 冻结评估样本 N=60（金标准纳入 30、排除 30）。评估指标分母：
  - 纳入召回率 = 正确建议纳入 / 金标准纳入 = 23/30
  - 纳入精确率 = 正确建议纳入 / AI 建议纳入 = 23/26
  - 排除精确率 = 正确建议排除 / AI 建议排除 = 26/26
  - 错误排除率 = 错误排除 / AI 建议排除 = 0/26
  - 纳入漏排率 = 错误排除 / 金标准纳入 = 0/30
  - 不确定率 = AI 不确定 / 样本 = 8/60
- 无摘要分层（补充口径）：冻结快照中有 5 条摘要为空（金标准纳入 4、排除 1），AI 均判「需人工判断」。剔除后样本 N=55：纳入召回率 23/26=88.5%、不确定率 3/55=5.5%。该分层仅作补充观察，不作为主指标。

## 2. 历史不一致状态修复（副本）

模拟旧版本遗留场景：

1. 题摘纳入 → 记录全文纳入；
2. 直接修改数据库为题摘排除（绕过新保护）；
3. 升级后重新将题摘改回纳入。

验证结果：

| 检查项 | 结果 |
|---|---|
| `list_stale_fulltext_decisions` 识别历史记录 | 1 条 |
| 重新纳入是否被阻止 | 是（`ValueError`） |
| 重置全文阶段 | 成功，写入审计（旧状态 → not_sought） |
| 重置后重新纳入 | 成功 |
| 修复后全文阶段记录 | 无（需重新评估全文） |
| 修复后 `纳入报告数` | 0 |
| 修复后 `全文未获取` | 18 |

结论：旧全文决定不会在重新纳入时被自动激活；历史记录可通过报告页或存储 API 重置。

# 科研文献助手

一个基于 Sciverse Agent Tools 的本地网页应用。无需编程即可检索学术文献、保存检索条件、浏览引用关系、阅读可访问的原文，并导出到 Zotero 或表格软件。

## 适合谁

- 希望通过网页界面查找研究论文的科研人员和学生
- 不想自己编写代码或直接使用命令行的 Sciverse 用户

## 首次启动

### Windows（推荐）

1. 安装 Python 3.10 或更新版本，并在安装时勾选“Add Python to PATH”。
2. 双击 `research_app/Start-Research-App.bat`。首次启动会自动安装所需组件，可能需要几分钟。
3. 浏览器打开应用后，在左侧输入从 [Sciverse 控制台](https://sciverse.space) 申请的 API Token。

如果双击启动器不成功，也可以在项目目录打开 PowerShell，运行：

```powershell
python -m pip install -r research_app/requirements.txt
python -m streamlit run research_app/app.py
```

浏览器地址通常是 <http://localhost:8501>。

### macOS / Linux

```bash
python3 -m pip install -r research_app/requirements.txt
python3 -m streamlit run research_app/app.py
```

随后在浏览器打开 <http://localhost:8501> 并输入 API Token。

## 使用方法

先打开左侧“研究项目”创建或选择项目，再进入检索、筛选和 AI 证据页面；检索快照、来源和证据会关联到当前项目。关闭浏览器后重新打开项目仍可继续。研究项目页可载入已保存的检索快照，并下载包含项目范围、来源、筛选状态和 AI 任务的项目清单 JSON。研究项目是唯一的新建入口；“系统综述筛选”页面只选择和筛选已有项目。筛选队列中每条候选可展开查看来源检索快照。研究项目页底部提供永久删除项目功能，需要输入项目名称确认，删除后该项目的候选、筛选决定、审计、检索快照和 AI 证据都会移除。

1. 选择“智能语义检索”，用一句话描述问题；或选择“条件筛选”，填写关键词、作者、年份、期刊/会议和学科。
2. 条件筛选默认只返回论文类文献（article/review/conference/preprint），会排除书籍章节、社论、勘误等；需要其他类型时选择“全部类型”。勾选“仅开放获取（OA）”只是按 OA 状态过滤，不代表平台有全文记录，某些主题下反而会减少 `doc_id` 覆盖。要只看当前页有全文记录的论文，请勾选“仅显示有全文记录（doc_id）”。语义检索不能可靠按类型过滤，但会自动按 `doc_id` 批量补全 `unique_id`；未匹配的结果会明确提示，仍可阅读但暂不能用于引用网络。
3. 结构化检索支持分页和年份排序；可从左侧加载字段目录，添加一个高级字段条件。
4. 勾选文献下方的“选择用于导出/加入项目”，可跨页选择后导出 CSV、RIS、BibTeX 或 Markdown；同一批选择也会用于加入系统综述项目。未选择时，导出和加入项目使用当前页全部结果。非中文标题可点击“AI 翻译当前页…”生成中文标题，翻译结果会缓存到本机。
5. 点击“查看文献”后可读取有权限的原文，并按页浏览引用、参考文献和相关工作。
6. 可保存常用检索；最近检索和已保存检索都显示在左侧栏。
7. 左侧页面导航进入“系统综述筛选”：默认使用当前项目，优先把主页已选择的文献加入候选队列；未选择时使用当前页全部结果。跨页选择会保留每篇文献所在页面的检索快照；同一快照重复导入不会重复累计统计。随后逐条标记纳入/排除/待定，并查看重复依据、审计记录和轻量筛选统计（完整 PRISMA 2020 口径在后续阶段提供）。身份冲突候选在人工解决前不能保存筛选决定。
8. 左侧“引用网络”：可选择当前会话结果或项目最近检索快照，选择中心论文，加载引用/被引/相关工作的一层关系，按需继续展开节点；可补全年份、期刊等元数据，按条件过滤，并导出 GraphML 或边列表 CSV。引用网络结果属于本页独立分析，不自动写入项目。
9. 左侧“趋势分析”：可选择当前会话结果或项目最近检索快照，统计年份、期刊、作者、学科、关键词、高被引和增长关键词；条件筛选可扩展到最多 5 页，页面显示样本量、请求次数、缺失率和截断风险，并导出统计 ZIP 或 PNG。切换项目或数据源会清除旧扩展样本；分析结果属于本页独立分析，不自动写入项目。若重复记录存在强标识符冲突，会保留为独立样本并提示人工核对。
10. 左侧“图表证据板”：可选择当前会话结果或项目最近检索快照，从最多 5 篇有全文记录的论文中提取图表（每篇最多 4 张），为每张图添加备注，并导出证据清单 CSV 或图片 ZIP。图表提取结果属于本页独立分析，不自动写入项目；是否能读以实际读取结果为准，`is_content_accessible=false` 的论文也可以尝试，单个失败不会阻塞其他结果。
11. 左侧“AI 证据与提纲”：从最近使用的 Base URL 中选择或填写自定义 OpenAI 兼容服务，配置 API Key 和模型名；从最多 5 篇论文中提取研究问题、方法、样本、发现、局限和引文，自动比对引句，逐篇人工核对/备注后导出证据表 CSV/Markdown，再生成带来源标注的 Markdown 综述提纲。API Key 只在当前会话使用。
12. 左侧“AI 领域扫描”：从当前搜索结果或项目最近检索快照选择最多 20 篇论文，按奠基/经典、近年进展、方法、应用、综述等类别分类，生成每篇 2–3 句核心概括、原文依据、领域主题和空白/痛点；结果保存为项目 AI 任务，可人工编辑、核对和导出 JSON。扫描结果不会自动改变筛选决定。

## Token 与隐私

网页中输入的 Token 仅用于当前会话，不写入本地数据库。检索条件、最近检索、研究项目、检索快照、项目文献来源、候选元数据、筛选决定、备注、审计记录、AI 任务和证据版本保存在 `~/.sciverse/research-workbench.sqlite3`，最近检索最多保留 50 条；不会保存检索结果全文或附件。左侧“已保存检索的备份”只导出/恢复已保存的检索条件 JSON，不包含研究项目、快照和审计记录。数据库升级前会自动备份；删除数据库文件会丢失本地记录。默认只在本机运行；不要将该应用公开到互联网或与他人共享 Token。

系统综述筛选中，候选会综合所有可用标识符（DOI、`unique_id`、`doc_id` 和 Unicode 规范化标题）进行跨字段匹配；例如一条记录有 DOI 和 `unique_id`，另一条只有相同 `unique_id`，也会识别为重复。若弱标识记录先入库、之后才出现带 DOI/稳定 ID 的同一论文，主候选会补全缺失元数据，但不会覆盖已有筛选决定、备注和审计历史。一个记录的多个强标识符指向不同候选，或同一类型强标识符与已有候选冲突时，会生成一个 `conflict:` 候选并在“重复记录”页标记为身份冲突，冲突标识符不会写入旧候选的别名映射，需人工核对。PRISMA 数量由候选和决定记录实时计算，导出的筛选 CSV 包含状态、排除原因、备注和更新时间。

引用网络的关系接口只返回标题和标识；年份、期刊、引用量需要点击“补全节点元数据”额外发起检索，页面会显示请求次数。未补全的节点标记为 `relation`，不会显示为已知元数据。关系接口只接受 Sciverse 的 `paper:...` unique_id；Semantic Scholar 数字 ID 或仅 DOI 的节点不能继续展开，页面会将其排除在“从哪个节点展开”之外。参考文献和被引关系保留方向；相关工作按无向虚线展示，并在 GraphML 中写入 `directed="false"`。

若已配置 `SCIVERSE_API_TOKEN` 环境变量，应用也可以直接使用该凭据，无需再次输入。

## 数据库维护

如果本地数据库曾运行过 v1.9.3 或更早版本，可能残留错误的强标识符别名。先关闭应用，在仓库根目录运行检查：

```powershell
python -m research_app.maintenance inspect
```

检查使用只读连接，不执行 Schema 迁移，也不修改数据库。若数据库版本较旧，`inspect` 会提示先运行升级：

```powershell
python -m research_app.maintenance upgrade
```

升级会先备份，再迁移到当前 Schema。确认问题后可运行修复：

```powershell
python -m research_app.maintenance repair
```

修复会先创建 `research-workbench.sqlite3.bak-时间戳` 备份，再删除能够确定归属的错误别名和孤立映射；无法确定归属的映射（包括候选缺少该类型规范标识、只有单个未知别名的映射）会保留并输出到 `ambiguous` 清单，需要人工核对。修复不会修改候选、筛选状态、排除原因、备注或审计历史。修复后建议重新运行 `inspect`，确认 `conflicts` 和 `orphans` 为 0，并人工处理 `ambiguous`。POSIX 系统上的备份文件权限会限制为 `0600`；权限设置失败时修复会中止。

旧版本可能重复导入同一检索快照，导致项目统计虚高。先检查：

```powershell
python -m research_app.maintenance stats
```

检查会对比项目存储计数与导入事件账本。新版本会为每次实际导入记录识别、重复和冲突数量；只有具备完整导入事件的项目才允许精确重建。确认后可用以下命令重建；不加 `--apply` 时只预览：

```powershell
python -m research_app.maintenance rebuild-stats --project-id <项目ID> --apply
```

`--apply` 前会自动备份数据库，并在输出中返回备份路径。旧版本项目没有导入事件账本，会在 `notes` 中标记为无法精确重建，不会根据快照数量猜测，也不会自动写入。

## AI 证据与提纲

“AI 证据与提纲”页面需要用户自备 OpenAI 兼容服务。默认 Base URL 为 OpenCode Go（`https://opencode.ai/zen/go/v1`）；填写 API Key 和模型名后，可对最多 5 篇论文提取结构化证据并生成 Markdown 提纲。也可选择“自定义 URL”连接其他服务。

- Base URL 和模型名会记录在本机 `~/.sciverse/ai-settings.json`，下次从下拉列表选择；选择历史 URL 会自动带出其上次使用的模型。
- 检索结果的 AI 标题翻译按模型和提示词版本缓存到 `~/.sciverse/title-translations.json`；翻译结果会标注为 AI 生成，不修改论文原始元数据。
- API Key 只在当前浏览器会话使用，不写入本地数据库、配置文件或源码；在会话未关闭时切换页面不需要重新输入，刷新或关闭浏览器后需重新输入。
- 每条证据保留论文 ID、模型、提示词版本和生成时间；引句会自动与输入文本比对，未匹配项会明确提示。
- 证据字段、引句和核对备注可直接编辑；逐篇标记“已核对”后，可导出证据表 CSV 和 Markdown。CSV 每篇一行，最多 3 条引句分列，便于在表格软件中筛选。
- 关联研究项目时，AI 任务、原始输出、人工修改和最终采用版本会保存到项目；重新打开同一项目可继续核对。自动保存只更新人工校订版本，只有勾选“我已核对这篇文献的 AI 证据”后才更新最终采用版本，不会覆盖 AI 原始输出。未关联项目时，编辑和核对只保留在当前浏览器会话。提纲导出附带模型和提示词版本。
- 提纲直接生成 Markdown；若模型仍返回 JSON 包装或输出被截断，应用会自动提取其中的 Markdown 正文，避免下载到原始 JSON。
- AI 失败按论文隔离，不阻塞其他论文；响应因输出长度被截断时，客户端会在有界预算内重试更大输出。不会自动写入 Zotero 或生成最终论文。

OpenCode Go 推荐模型为 `glm-5.3-flash` 或其他走 `/chat/completions` 的非推理模型 ID（不要加 `opencode-go/` 前缀）。客户端会自动发送稳定的 `x-opencode-session` 会话头和专用 User-Agent。若反复出现 `finish_reason=length` 和空内容，说明推理过程耗尽了输出预算，应换用非推理模型。

## AI 领域扫描

“AI 领域扫描”使用同一套 OpenAI 兼容配置，从当前会话或项目检索快照中选择最多 20 篇带摘要的论文：

- 逐篇分类为奠基/经典、近年进展、方法、应用、综述或其他
- 生成 2–3 句核心概括、分类理由、原文依据和置信度
- 汇总领域主题、研究空白和痛点，并尽量绑定论文 ID
- 结果保存为项目 AI 任务，和证据版本一样区分 AI 原始输出、人工校订和最终采用
- 人工可修改分类、概括和备注；扫描结果不会自动修改筛选状态，也不会自动排除文献

## Windows 便携版 exe

需要构建便携版时，在仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build_desktop.ps1
```

构建结果位于 `dist/SciverseResearchWorkbench.exe`。双击后会启动本地服务并自动打开浏览器；不需要命令行。首次构建需要安装 PyInstaller，耗时和体积取决于当前 Python 环境。当前产物为 109,314,428 字节（约 104 MB）；本机最新构建首次启动实测约 7.6 秒，干净 Windows 机器可能更慢。onefile 首次启动需要解压，请等待浏览器自动打开。

AI 页面的 API Key 只在当前会话输入，不写入 exe 或本地数据库；Base URL 和模型名保存在本机 `~/.sciverse/ai-settings.json`。Sciverse Token 仍按原有方式从环境变量或凭据文件读取。

### 故障排查

- 浏览器没有自动打开：手动访问 `http://localhost:8501`；如果端口被占用，应用会依次尝试 `8501-8600`。
- 双击后长时间没有反应：先等待 30 秒；确认杀毒软件没有拦截 PyInstaller 单文件程序，可尝试把 exe 放到普通本地目录后重新运行。
- 提示缺少文件或启动即退出：重新运行 `scripts/build_desktop.ps1` 生成 exe；不要只复制 `dist` 中的临时文件。
- 页面能打开但检索失败：检查 Sciverse Token；AI 功能还需单独配置 API Key。
- 端口被其他程序占用：关闭其他 Streamlit/本地服务，或重启应用让它选择新端口。
- 数据异常：本地记录位于 `~/.sciverse/`（Windows 为 `C:\Users\<用户名>\.sciverse`）；删除前请先备份 `research-workbench.sqlite3`。

### 卸载

1. 关闭黑色命令行窗口或结束 `SciverseResearchWorkbench.exe` 进程。
2. 删除 `dist/SciverseResearchWorkbench.exe`。
3. 如需清除本地检索、筛选和 AI 服务地址记录，再删除 `~/.sciverse/`；这会丢失工作台本地数据，不会影响 Zotero。

### 干净 Windows 验收清单

1. 准备一台未安装 Python 的 Windows 10/11 机器，复制 exe 到本地目录。
2. 双击 exe，记录从双击到浏览器打开的时间。
3. 确认首页可打开，执行一次检索并导出 CSV。
4. 打开“AI 证据与提纲”，确认页面可编辑证据和导出。
5. 关闭应用，确认没有残留 `SciverseResearchWorkbench.exe` 进程。

## 说明

- 论文全文的可读性取决于文献资源和 Sciverse 账号权限。
- 当前 Sciverse API 未提供 CNKI、Scopus、Web of Science 等数据库名称字段，因此应用不能按这些数据库勾选过滤；可按文献类型、来源类型、OA 状态和语言过滤。若后续 API 增加数据库字段，再接入数据库选择。
- “智能语义检索”支持平衡、更快和更深入三种检索方式。
- 请求超时为 30 秒；`400/401` 不自动重试，`429` 遵循 `Retry-After` 且自动等待最多 5 秒，`5xx` 最多重试 2 次。
- `429` 建议等待时间超过 5 秒或网络超时时，应用会提示用户稍后手动重试。
- 若出现纯文本 `Bad Request`，通常是 Token 粘贴时混入了控制字符。请在页面左侧重新粘贴 Token；在 CMD 中登录时用鼠标右键或 `Shift+Insert` 粘贴，不要按 `Ctrl+V`。
